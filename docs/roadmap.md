# Roadmap

Each phase ends with a summary and Bas's approval before the next starts.

**Status:** Phase 0 done (2026-10-27). Phase 1 done pending review (2026-10-27): all acceptance checks are automated in `tests/e2e/walls-rooms.spec.ts`. Phase 2 done pending review (2026-10-27): acceptance is covered by `tests/e2e/{openings,floors,stairs,ceilings,threed,phase2-acceptance}.spec.ts` and `tests/unit/domain/phase2RoundTrip.test.ts`.

**Phase 2 delivered:** door tool (swing, double swing, sliding, pocket, doorway) and window tool (fixed, tilt-turn, casement, sliding, top-hung) with 2D symbols, drag along and between walls, inspector and flip buttons; wall pieces feeding 2D and 3D, with openings cut as holes plus frames, leaves and glass; floor panel (add above/below, copy walls, rename, re-height, delete with confirmation), floor switcher, ghost floor with ghost snapping and a 3D stack mode control; straight, quarter-turn and half-turn stairs with UP/DN symbols on both floors and riser/tread warnings; derived floor slabs with stair voids; **sloped ceilings pulled forward from Phase 4** (ceiling planes, roof-from-walls saddle roof, clipped walls, headroom bands, usable area, tall-opening warning; schema v3). Spiral stairs were dropped. Dormers, hips and curved roofs remain out of scope.
